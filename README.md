# C# Learning Lab — 詳細解説拡充版

**8章32レッスンの本編に、処理順・状態変化・仕組み・失敗と修正を掘り下げる教材を追加した静的サイトです。**

## ① 開く

ZIPをすべて展開し、ルートの `index.html` をブラウザーで開きます。HTML・CSS・表示用スクリプト・検索データは同梱しています。教材閲覧にC#のビルドやパッケージ取得は不要です。

端末・ブラウザーによってローカルファイルの保存領域の扱いが異なります。学習記録を継続する場合は、同じ配置と同じブラウザーを使い、設定画面からバックアップを書き出してください。学習データは端末内だけに保存され、自動的に別端末へ同期されません。端末の制限で保存できない場合は、画面の警告に従って下書きをコピーして保管してください。

## ② 学ぶ

本編 → 対応する詳細解説 → 基礎・標準・応用演習 → 確認問題、の順に進めます。仕組みが曖昧になったら、学習ガイドの「コードの読み方」「エラーの調べ方」「機能の選び方」「用語集」へ戻れます。

| 教材 | 内容 |
|---|---|
| 本編 | 8章・32レッスン。元の本文・例・演習を維持して拡充 |
| 詳細解説 | 32ページ。全レッスンに対応 |
| 補助教材 | 7ページ。実行の仕組み、メモリ、処理順、失敗、比較、非同期、HTTP・DI |
| 用語集 | 180語。定義・役割・必要性・具体例・関連レッスン |

| 公開HTML | 合計80ページ |

ページ数・文字数を上限として設計していません。説明のまとまりで本編と詳細解説をつなぎ、長文は目次・現在位置表示・見出し・図・表・折りたたみで整理しています。

## ③ C#を手元で確かめる

対象は **.NET 10 / C# 14** です。コード入力欄は下書きであり、ブラウザー内でC#を実行する機能ではありません。確認問題の選択結果と、C#コードの検証結果は別です。

.NET SDKを用意したPCで、展開したフォルダーをターミナルで開き、まず次を確認します。

```powershell
dotnet --list-sdks
dotnet build samples/expanded/deep/01/example-01/Example.csproj
dotnet run --project samples/expanded/deep/01/example-01/Example.csproj
```

コードパネルの種類を確認してから操作してください。失敗例・部分例・テスト例は、そのまま独立したコンソールアプリとして起動するものではありません。WebサンプルはWeb SDKのプロジェクトで動かします。ファイル操作は練習専用の保存先で試してください。

## 検証状態

**C#の `dotnet build` / `dotnet run` は未検証です。** 制作環境にSDKがなく、公式配布先からの取得もできませんでした。想定出力を実測結果として扱っていません。

全80ページの内部リンク・見出し・目次を静的検査し、実際のローカルHTTP配信も検査しました。ChromiumのURL直接移動は環境の管理制限で拒否されたため、ブラウザー検査は生成HTML・CSS・表示用スクリプトを直接読み込んだDOM表示検査です。PC・タブレット・モバイル相当の3幅を対象としています。保存ロジックはメモリ上の代替保存領域で検査し、実ブラウザーの永続保存・実機Safari・ネイティブ200%ズームと同一視していません。

結果と未検証項目の詳細は [検証記録](docs/VALIDATION.md) を参照してください。
