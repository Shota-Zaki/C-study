# C# Learning Lab — 図解・実例版

Version 5.0.0 / 2026-09-15

8章・32レッスン、詳細解説32ページ、合計80ページのC#教材です。既存の96演習・160問・180語を維持し、32種類のSVG図解と64本の独立した実例コードを追加しました。

## 成果物

`C-study_public.zip` は公開用です。ZIPの直下に `index.html` があり、HTML・表示用アセット・本文から参照するサンプルだけを収録します。

`C-study_visual_release.zip` は編集用一式です。公開用ファイルに加え、教材データ、生成スクリプト、既存236件と追加64件のC#プロジェクト、変更履歴、検証記録を収録します。

ローカル閲覧は、ZIPをすべて展開して `index.html` を開きます。保存機能の継続利用は同一オリジンでのHTTP/HTTPS配信を前提とし、`file:` URLでの永続性は保証していません。

## C#の実行

ブラウザー内でのC#実行は未搭載です。無料の静的ホスティングでもWebAssemblyを配信できますが、この作業環境では.NET SDK・WebAssembly実行基盤を取得・検証できませんでした。費用上の不可能と判断したものではありません。

下書き欄は編集・保存用です。選択式確認問題の採点と、C#プログラムの実行は別機能です。想定出力は実行結果を装ったものではなく、コードを静的に読んで記載した期待値です。

追加したサンプルは `.NET 10 / C# 14` を対象とします。SDKを用意した環境では、例えば次のコマンドで個別に確認できます。

```sh
dotnet build samples/visual/05/case/Example.csproj
dotnet run --project samples/visual/05/case/Example.csproj
```

.NETのビルド・実行は今回未検証です。WebサンプルはローカルのWebアプリとして動作するコードであり、この教材サイトにサーバー機能を追加するものではありません。

## 再生成

```sh
python -m pip install -r scripts/requirements.txt
python scripts/build_visual.py
python scripts/audit_visual.py
```

公開HTMLの生成入口は **`scripts/build_visual.py`** です。`build_expanded.py` はその内部から使う元教材生成処理であり、単独で実行すると図解版のレイアウトは適用されません。

詳細は [保守手順](docs/MAINTENANCE.md)、[変更箇所](docs/CHANGELOG_VISUAL.md)、[検証記録](docs/VALIDATION.md)、[無料公開とC#実行の検討](docs/HOSTING_AND_RUNNER.md) を参照してください。

## 検証の範囲

80ページの内部参照・見出しID・画像参照を検査し、参照切れとID重複はありませんでした。ChromiumにHTMLとローカルアセットを直接読み込ませ、3画面幅の表示と操作、および図版・追加コードの静的検査を含む213項目を確認しました。

ブラウザーのURL直接移動が環境の管理制限で拒否されたため、実配信URLのE2E、実オリジンの永続保存、Safari/iPhone/iPad実機、C#のコンパイル・実行、Cloudflare/GitHubへの公開は未検証です。保存ロジックのテストには明示的なメモリ上の代替保存領域を使っています。
