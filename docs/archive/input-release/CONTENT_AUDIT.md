## 結論

最終教材は、特定の既習言語を前提にしないC#単独教材として再構成した。8章32レッスンの順序、問題・演習・制作課題の数量を維持し、比較専用だった説明は単純削除ではなくC#側の概念・内部動作・判断基準へ置換した。

## 内容の厚み

元教材から比較専用フィールドだけを除外したC#本体部分を基準に、文字列フィールドの総文字数を比較した。

- 基準: 230,050文字
- 最終版: 240,097文字
- 差分: +10,047文字（+4.37%）
- 基準より短くなったレッスン: 0 / 32
- 最小増加レッスン: Lesson 03、+228文字

この数値は「文章の質」自体を測るものではないが、比較説明の除去によって教材量を削っていないことを確認する定量チェックとして使用した。

## 単独教材化の監査

以下を全文検索と構造検索の両方で確認した。

- 旧比較教材の固有語、ツール名、型名、構文例の残留がない
- 旧言語名をキーにした比較専用データフィールドを教材JSONから除去
- `compare` 相当の比較専用フィールドを除去
- 「他言語では〜」「〜相当」「〜に近い」といった比較前提の説明を、C#の仕組みを直接説明する文へ置換
- JavaScript はサイト機能に必要な技術名として維持
- 各レッスンに `csharp_focus` を設け、C#側の要点・コード・採用理由を明示
- 比較表由来の内容は `focus_table` としてC#内の選択基準・注意点へ再構成

最終成果物全体に対する禁止語・意味パターンの自動監査は `scripts/validate_static.py` に含めている。

3. オブジェクト指向 — クラス、プロパティ、継承、インターフェイス
4. C#らしい型の使い方 — 値型/参照型、record、ジェネリック、例外/using

6. 保存と非同期処理 — ファイル、JSON、日時、カルチャー、async/await、キャンセル
7. 実務への橋渡し — プロジェクト、NuGet、デバッグ、単体テスト、入力検証、HTTP

## 既知不具合の回帰確認

- Lesson 16: 通常文字列内に実改行が混入しないことを確認。`StringReader("C#\\n.NET")` の形式を維持。
- Lesson 21: JSON文字列内の引用符をエスケープした状態で保持。
- Lesson 28: `StringContent` に渡すJSON文字列の引用符をエスケープした状態で保持。

3件とも `validate_static.py` の固定回帰テストと `audit_csharp_code.py` のレキシカル検査対象にしている。

## 学習機能の表現監査

演習欄は一貫して「コード下書き」として扱う。ブラウザー内でC#をコンパイル・実行・自動採点しているように見える表現は採用していない。確認問題の採点は選択式問題だけを対象とする。
