# 詳細解説拡充版の変更記録

## 教材

元の8章32レッスン、96演習、160問、3制作課題を維持し、32の詳細解説、7つの補助教材、180語の用語集を統合しました。本編にも詳細教材の導入部分、前後の接続、同一ページ内の用語説明を追加しました。全640選択肢と全96演習に、それぞれの問題内容に合わせた説明を補強しました。

## 監査中の修正

| 位置 | 修正前 | 修正後・理由 |
|---|---|---|
| Lesson 05・確認問題2 | if/else ifとswitch式の包含判定が混ざり、どの構文の結果か曖昧 | 入力82とif/else ifを明示。switch式のコンパイル診断と実行時の条件順を区別 |
| 詳細32・一覧取得の見出し | Listへ返す前にToArray | 一覧を返す前にToArrayで確定する理由。実際の戻り値が配列であることに合わせた |
| 生成処理・詳細導入の抽出 | ルートに対する`:scope`選択で導入が空になった | 直下のsectionを明示取得し、全32本編で2節の挿入を確認 |
| ページ内移動 | scroll-paddingとscroll-marginが重なり、現在位置が前の節を示す | 余白を調整し、移動先の見出しと位置表示を一致させた |
| 下書き保存 | 書き込み失敗時も保存済みと表示し得た | 保存成功時だけ保存済み。失敗時は警告し、入力欄の内容を維持 |
| 保存データ読み込み | 壊れた保存データを空状態で上書きし得た | 読み込み失敗時は元のデータを保護し、正常なバックアップの明示読込まで保存しない |
| コピー | Clipboard APIの失敗処理がなかった | 失敗を捕捉し、手動コピーの案内へ切り替える |
| 検索 | 新しいページ種別を制作課題と表示 | 本編・詳細解説・補助教材を正しく区別 |
| モバイルメニュー | 開閉だけでキーボード焦点の復帰が不十分 | Escape、開閉時の焦点、メニュー内のTab移動を補強 |
