# Project brief

C#を初めて学ぶ人が環境構築からWeb APIまで、概念・内部動作・処理順・状態変化を理解し、例題を実行できる教材を公開する。

元原稿はLibraryから取得したCSharp_Learning_Lab_Expanded.htmlとZIP。8章32レッスン、160問、96演習、64例題、32修正例、192独立サンプル、3制作課題を維持する。Repositoryは開始時に未初期化。

対象は全文のC#単独説明化、全面UI再設計、検索/進捗/下書き/JSON入出力、レスポンシブ、アクセシビリティ、SEO、実行検証、静的公開。本文を主役とし、他言語の知識を前提にしない。

.NET 10 / C# 14を基準とする。教材サイトは静的構成、C#コードは利用者のSDKで実行する。アカウントや有料サービスに依存しない。ブラウザー上の入力欄をコンパイラーや自動採点と表示しない。

成功条件は、全レッスンを順序どおり利用でき、問題の全選択肢解説と3段階の演習へアクセスでき、有用な元説明を失わないこと。テスト結果と未検証を区別し、Repositoryから作業を復元できること。
