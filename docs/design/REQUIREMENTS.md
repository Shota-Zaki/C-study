# Requirements

FR01: 32レッスンを独立した静的ページで提供。概念、仕組み、構文、例題、処理追跡、修正前後、基礎/標準/応用、5問と全選択肢解説、到達確認、出典を保持。
FR02: 他言語比較と前提説明を撤去し、C#だけで成立する説明を補う。文量だけで充足判定しない。
FR03: 全文検索、章ナビ、ページ内目次、前後移動、3制作課題、用語集、環境構築ガイド。
FR04: 完了/復習/回答/下書きを端末内保存。サイズ・形式・値を検証するJSON入出力。保存不可や破損で既存データを勝手に初期化しない。
FR05: コード言語表示、コピー、サンプルダウンロード。下書きUIとSDK実行を区別。
FR06: README、favicon、description、OGP、canonical、sitemap、404、静的公開手順。

NFR01: PCは章ナビ/本文/目次。Tabletは本文優先、Mobileはdialogドロワー。コードと表だけ内部横スクロール。
NFR02: semantic HTML、skip link、visible focus、キーボード/Escape、ラベル、色だけに依存しない表示、reduced-motion、明暗テーマ。
NFR03: 原稿データからページを生成。外部フォント/CDN/重いランタイム依存を避ける。
NFR04: インポートを検証後に確認して反映。エスケープ/textContentでXSSを防ぐ。
NFR05: mainに設計/タスク/ログ/旧版/移行用ファイルを置かない。

Acceptance: 全32レッスン/160問/96演習を構造検査。3画面幅と明暗で横溢れ/操作を確認。保存/復元/不正JSON/コピー/検索/focusをテスト。可能な環境でC#をビルド実行し、未検証を明記。公開URLは設定後に別途実測。
