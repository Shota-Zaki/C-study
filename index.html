この教材の使い方

  1. 本文で概念と内部の仕組みを理解する。
  2. コード例を処理順・値の変化と一緒に追う。
  3. 基礎・標準・応用の下書きを作り、手元の.NET SDKで実行する。
  4. 確認問題を採点し、誤答選択肢の理由まで読む。
  5. 復習マークと進捗をlocalStorageへ保存する。
実行環境

教材サイト自体は静的HTMLです。C#コードはブラウザー内で実行せず、.NET SDK 10系のdotnet build / dotnet runで確認します。
